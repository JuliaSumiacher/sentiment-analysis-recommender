# Sentiment Analysis Recommender

A project combining dataset creation via web scraping and a recommendation system incorporating sentiment analysis, organized into two Jupyter notebooks.

## Project Structure

- `data_collection_web_scraping.ipynb` — Jupyter notebook focused on web scraping and building the dataset.
- `sentiment-analysis-recommender.ipynb` — Jupyter notebook implementing the recommendation workflow with sentiment analysis.

## Usage

1. Open `data_collection_web_scraping.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab to collect and prepare the dataset.
2. Open `sentiment-analysis-recommender.ipynb` and run the cells sequentially to execute the sentiment analysis and recommendation steps.
